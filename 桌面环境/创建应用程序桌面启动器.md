# 创建应用程序桌面启动器

通过创建应用程序 `.desktop` 文件，为 Linux 应用程序创建图形化启动入口

# 创建应用程序 .desktop 文件

```shell
mkdir -p ~/.local/share/applications

vim ~/.local/share/applications/<application-name>.desktop
```

参数说明：

- `application-name`：文件名，建议使用英文

配置内容：

```text
[Desktop Entry]
Name=<application-name>
Exec=/path/to/application
Icon=/path/to/icon
Type=Application
Terminal=false
```

参数说明：

- `Name`：应用程序名称，可以使用中文
- `Exec`：应用程序可执行文件的绝对路径
- `Icon`：应用程序图标的绝对路径
- `Type`：应用程序类型，固定为 `Application`
- `Terminal`：是否在终端中启动，图形化应用程序使用 `false`

# 刷新应用程序菜单

通常重新打开应用程序菜单即可

如果没有显示，可以执行：

```shell
update-desktop-database ~/.local/share/applications/
```
